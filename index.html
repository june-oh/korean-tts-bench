문장 선정 근거 Test design

KO-TTS Arena 공개 원고에는 제품 코드와 가격, 주문번호, 전화번호, 영문이 섞인 안내, 운행 지연 안내가 들어 있습니다. CoreaSpeech는 숫자·영문 정규화를 다루고 한국어 시험셋을 clean, noisy, numeric으로 나눕니다. 여기서는 그중 텍스트에서 재현할 수 있는 현상을 택해 문장을 새로 작성했습니다. 이 페이지의 결과를 두 원본 벤치마크 점수와 직접 비교할 수는 없습니다.

  1. KO-TTS Arena 공개 원고. 앞자리 0, 편명·탑승구, 긴 안내에서 숫자 보존과 낭독 완결성을 검사합니다.
  2. Kwon 외, CoreaSpeech (NeurIPS 2025) · 저자 데모. 숫자·영문 표기를 포함하고 P13/P16에서는 같은 내용을 숫자와 한글로 써서 전처리의 영향을 들어봅니다.
  3. 국립국어원, ‘꽃잎’의 발음. ‘꽃잎’의 ㄴ 첨가와 비음화를 들을 때 참고합니다.

자모·동형 표기·정정 발화·종결 억양은 이 데모에서 추가한 탐색 문항입니다. 청취 포인트는 오류를 발견하기 위한 단서입니다. 다른 자연스러운 읽기도 허용하며, 청취자 조사나 MOS 평점은 아직 없습니다.

실험 조건 Protocol

모든 샘플은 AI 합성 음성입니다. 로컬 모델은 Apple M1 CPU에서 모델 로드 후 별도 문장으로 예열하고 3회 측정했습니다. 첫 시도의 음원과 시간을 그대로 게시합니다. API 모델은 문장당 1회 요청하고 응답 오디오 전체를 받을 때까지 측정했습니다. 이 시간에는 네트워크·서버 대기가 포함됩니다. RTF는 생성 시간 ÷ 게시 음성 길이입니다. 첫 소리가 나는 시점이나 서버 자체의 처리 속도를 나타내지는 않습니다.
